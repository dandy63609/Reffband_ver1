## Numbered Findings List

### [01] External File/CSS Patching Scripts in Project Root
- **Priority:** HIGH (Hard Gate)
- **Violated Rule:** R-33 — No File/CSS Patching via Scripts
- **Location:** `patch_preview_mobile.py`, `patch_preview_script.py`
- **Reason:** Features must be built directly into source code; external Python regex patch scripts modifying HTML/CSS must be removed and consolidated into native project styles.

---

### [02] Clickable `<div>` Gatekeeper Cards Lacking Keyboard & ARIA Access
- **Priority:** HIGH (Hard Gate)
- **Violated Rule:** R-32 — Keyboard Accessibility, R-39 — Accessible Semantics
- **Location:** `components/leaves/leaf-01-cover.tsx` (lines 63–132)
- **Reason:** Role selection cards use `<div onClick>` without keyboard focus (`tabIndex={0}`, Enter/Space key support, `role="button"`), and contain nested interactive elements.

---

### [03] Viewport Height Lock (`100vh`) and `overflow: hidden` on Mobile Viewports
- **Priority:** HIGH (Hard Gate)
- **Violated Rule:** R-03 — Mobile Responsiveness, `antislop-layoutmobile`
- **Location:** `app/globals.css` (lines 9–19)
- **Reason:** Hardcoding `height: 100vh; overflow: hidden;` cuts off content behind dynamic browser address bars on mobile phones; must use dynamic viewport units (`100dvh`) and allow responsive overflow handling.

---

### [04] Booking Handshake Modal Lacks Keyboard Dismiss (`Escape`)
- **Priority:** HIGH (Hard Gate)
- **Violated Rule:** R-32 — Keyboard Accessibility
- **Location:** `components/leaves/leaf-04-discovery.tsx` (lines 406–545)
- **Reason:** Modals must be dismissible via the `Escape` key to prevent keyboard navigation trapping.

---

### [05] Fabricated Trust Claim & Unverified Score Badge in Leaf 05

- **Violated Rule:** R-36 — No Fabricated Claims, R-17 — Data & Numbers
- **Location:** `components/leaves/leaf-05-scorecard.tsx` (line 18)
- **Reason:** Claiming `"SCORE: 98/100 (WCAG AAA PASS)"` in user-facing production UI is an unverified compliance assertion.

### [06] Em Dash (`—`) in User-Facing Navigation & Page Metadata
- **Priority:** HIGH (Hard Gate)
- **Violated Rule:** R-02 — Copywriting (Em Dash Ban)
- **Location:** `components/stage/reader-controls.tsx` (lines 15–19), `app/[bandSlug]/page.tsx` (lines 21, 40)
- **Reason:** The em dash (`—`) is strictly forbidden in UI text and metadata; replace with colons, hyphens, or commas.
