# Reffband MVP

Reffband adalah platform showcase & discovery band lokal Indonesia dengan stage booklet 3D (Japanese Orihon accordion style), Band EPK Studio Wizard, dan integrasi direct booking via WhatsApp.

## Tech Stack
- **Framework:** Next.js 15 (App Router)
- **UI & Motion:** Tailwind CSS, Framer Motion, Lucide React
- **Language:** TypeScript
- **Backend / BaaS:** Supabase Cloud

## Getting Started

Jalankan development server:

```bash
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000) di browser Anda.
